# Lab change-review implementation Loop Contract

**Applicable goal:** [G008-001](../goals/G008-001/contract.md)

For each bounded implementation round, inspect the active Goal State and LAB-M003 mission, change only allowed surfaces, then evaluate the resulting visitor journey and runtime behavior. Preserve the distinction among deterministic wiring tests, mocked model responses, live provider evidence, and human product judgment. On failures, record the observable gap and re-enter the smallest relevant code or architecture surface. A new infrastructure or public authority requirement changes the contract only through a recorded decision; the loop cannot approve deployment or Landing for itself.

The retained floor is `corepack pnpm check`, Lab browser journeys when UI changes, a real worker/run retrieval check, and accessible keyboard/mobile interaction. Credentialed provider calls and a three-case quality set are required before claiming an end-to-end live review. An unavailable credential yields an explicit pending item, not a passing result.
