# Reference Material

Reference material preserves supplied input and provenance. Its presence does not automatically make every recommendation an adopted project decision.

For current methodology, start with the [Mission Control reference index](../mission-control-reference/README.md) and [source authority notes](../reconciliation/canonical-reference-notes.md). Erik's 2026-09-25 clarification establishes Mission Control as generally tool- and team-agnostic. Flight Deck is an optional, opinionated implementation for an engineering team, including an observability layer and other coordination/governance capabilities. Existing tools could collectively replace its capabilities. Flight Deck-specific plans apply to that future product and must be reconciled against current methodology before use.
